For the Week 11 CI/CD Workflow Lab, I used my existing Personal Portfolio Page project (https://github.com/a5ura/robotics-portfolio). Its GitHub Actions workflow automatically runs on pushes and pull requests, installs dependencies, executes 22 Node.js unit tests, validates HTML and JavaScript, builds the static site, and runs 13 Playwright browser checks before deploying the main branch to GitHub Pages. GitHub Actions run 42868682798 failed during browser installation because the runner image was incompatible with the pinned Playwright version. The workflow was corrected to use Ubuntu 24.04, and run 42868833952 passed both testing and deployment; a later run, 42899331317, also succeeded. To demonstrate the required broken-test/fix cycle, I used an isolated local copy of the actual portfolio test files: 22 tests passed initially, an intentionally incorrect theme assertion produced 21 passes and 1 failure, and restoring the assertion returned all 22 tests to passing. I have included the workflow configuration, test execution evidence, deployment assumptions, and a proposed plan for monitoring availability, errors, accessibility, and key user interactions. The intentional failing-test exercise was local and was not pushed to GitHub.
